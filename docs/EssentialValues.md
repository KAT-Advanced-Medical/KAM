| Successful A. Carbonate Use Requirements (Blood Pressure first value) |  |  |  |  |
| :---: | :---: | ----- | :---: | :---: |
| Stable set of vitals | Chance decreases gradually |  | Max. chance (default 50%) | Chance decreases gradually |

| **Successful Reorientation Requirements (Heart Rate)** |  |  |  |  |
| Stable set of vitals | Chance decreases gradually |  | Max. chance (default 50%) | Chance decreases gradually |
|  | 40 ←79 bpm |  | 80 bpm | 81 → 220 bpm |

Chances of successful Reorientation or Ammonium Carbonate usage (i.e. wakeup chances) are dependent on settings. Upon reaching stable vitals, patients will with given probability wake up on their own. Epinephrine boosts the wakeup probability.  
CA (Cardiac Arrest) time may vary by 10% (by default 5 minutes \+/- 10%).
