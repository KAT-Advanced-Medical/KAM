# **Airways and Lungs** {#airways-and-lungs}

---

Please consider that:

* Thorax injury results in SpO2 loss even if no occlusions/ obstructions are present. [Coughing sound](https://drive.google.com/file/d/1lOKgpSDP9u9GfQf1TVVIBp-ISbqRWlTL/view?usp=sharing) can be heard every 30 seconds if thorax injury is present, provided the patient is conscious.  
* In hardcore mode (settings) checking for thorax injury is done through auscultating lung sounds and requires using a stethoscope and listening to the sounds, outside the hardcore mode it will show up in the overview on the chest.  
* More than one thorax injury might be present at the same time. Pneumothorax develops in stages. Once stage 4 is reached, there is a chance of it becoming an advanced pneumothorax resulting in TPTX or HPTX. The SpO2 loss increases with each stage and might not be noticeable in the beginning. SpO2 loss is higher while unconscious. If pneumothorax is present and you get shot again, advanced pneumothorax will occur resulting in TPTX or HPTX.  
* Fluid Draining requires AAT Kit, Needle Decompression requires AAT or NCD Kit.  
* Hemothorax causes internal bleeding.  
* Screen black flashing indicates decreasing Sp02 level.  
* Sp02 gain can be increased (loss decreased) by the use of BVM.  
* Faster breathing rate indicates higher HR.  
* “Deep penetrating wound” notification may be present in the medical overview. It means that a certain damage threshold has been crossed resulting in a thorax injury with given probability. Both the threshold and the thorax injury probability depend on settings.  
E.g. threshold \= 0.6, damage \= 0.7 (threshold crossed) → 50% chance of thorax injury (value depends on settings)  
* Oxygenation Period length is defined in settings. It is a period of time that starts after 30 compressions (c.a. 18 seconds of CPR) during which BVM is more effective \- it leads to SpO2 increase even though cardiac arrest is still present.

| Injury Type | Lung Audio Profile | Required Surgical / Field Equipment | Field Treatment Flow |
| :--- | :--- | :--- | :--- |
| **Pneumothorax (PTX)** | Short Breath | Chest Seal, NCD Kit, or AAT Kit | Apply Chest Seal → Auscultate. If sound persists, execute Needle Decompression. |
| **Tension Pneumothorax (TPTX)** | Short Breath | Chest Seal, NCD Kit, or AAT Kit | Immediate Needle Decompression or AAT Kit decompression. |
| **Hemothorax (HPTX)** | Cracking Sound | Chest Seal, AAT Kit | Apply Chest Seal → Perform Fluid Draining utilizing AAT Kit → Re-auscultate. |


\*Please consider that these files resemble full soundtracks for each injury. You may hear only part of the recording in the process of auscultating\! Auscultating twice increases the chances of determining the injury type correctly.

| Status | Treatment | Sidenotes |
| :---: | ----- | ----- |
| Occluded | <ul><li>Accuvac</li><li>Head Turning</li><li>Recovery Position</li></ul> | Perform till successful. |

## **Recovery Position**

The recovery position prevents occlusions and obstructions from happening, clears the airway but makes certain actions unavailable until the recovery position is canceled.

|  | Conditions for the action to appear |  |
| :---: | :---: | :---: |
| Unconscious | Not in recovery position | No Guedel Tube |
| No King LT | Not in a vehicle | Not in a stretcher |

|  | Canceling the action |  |
| :---: | :---: | :---: |
| Carrying | Dragging | Putting into a vehicle |

|  |  | Action prevents you from using following items/ actions on the patient |  |  |
| :---: | :---: | :---: | :---: | :---: |
| Guedel Tube | King LT | Accuvac | Chest Seal | AAT Kit |
| Overstretch | Turn Around | AED | CPR | FAST IO |

## **Check Breathing**

Checking Breathing (action on head) allows checking for kidney failure (see **Kidney Function**) but also provides clues that might help in quick determination of probable reasons behind low Sp02. Following outcomes of breath check can be present:

* Normal		→	 No issues present  
* Shallow	→	 Pneumothorax present  
* None		→ 	One or more of the following:  
  * No HR/ Dead  
    * Airways obstruction/ occlusion  
      * Hemothorax/ Tension Pneumothorax present

## **Inspect Chest**

Inspecting the chest (action on chest) is a fast way of estimating issues with breathing. Following outcomes of Inspect Chest can be present:

* Chest rise and fall observed	→	Regular breathing  
* No chest movement		→	Not breathing  
* Uneven chest rise and fall	→	PTX  
* Chest sides are uneven	→	PTX or TPTX or HPTX and not breathing  
* Skin is rigid, looks bruised	→	HPTX

**Glossary of terms:**  
PTX	-	Pneumothorax  
TPTX	- 	Tension Pneumothorax  
HPTX	-	Hemothorax

## **Cyanosis**

Checking cyanosis is a way of estimating the SpO2 without the use of medical items. Cyanosis can be checked on arms without tourniquets or on the head. It will appear on the injury list automatically if enabled.

| Status | SpO2 level (default settings) |
| :---: | :---: |
| No Cyanosis | <90 ; 100> |
| Slight Cyanosis | <75 ; 90) |
| Mild Cyanosis | <66 ; 75) |
| Severe Cyanosis | <0 ; 66) |
